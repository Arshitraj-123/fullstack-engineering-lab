NAME

library-catalog-api — a small RESTful API for managing a library's book catalog

SYNOPSIS

npm install
npm start
 
# server starts on http://localhost:3000

DESCRIPTION

This service exposes CRUD operations over a collection of books, plus two small workflow actions (checkout / return) layered on top of the plain REST verbs. Data lives in memory for this demo and reseeds on every restart.

All responses are JSON. Successful responses are shaped as { "data": ... } (list endpoints add a count); errors are shaped as { "error": { "message": ... } }.

ENDPOINTS

Method Path Description
GET /api/books List books. Optional ?author= and ?available= filters.
GET /api/books/:id Fetch a single book by id.
POST /api/books Create a book. Requires title, author, isbn, publishedYear.
PUT /api/books/:id Replace a book's fields entirely.
PATCH /api/books/:id Update one or more fields.
DELETE /api/books/:id Remove a book from the catalog.
POST /api/books/:id/checkout Mark a book unavailable. 400 if already checked out.
POST /api/books/:id/return Mark a book available again.
GET /api/health Liveness check.

EXAMPLES

List every available book by Fowler:

curl "http://localhost:3000/api/books?author=Fowler&available=true"

Add a new book:

curl -X POST http://localhost:3000/api/books \
  -H "Content-Type: application/json" \
  -d '{
    "title": "Refactoring",
    "author": "Martin Fowler",
    "isbn": "9780134757599",
    "publishedYear": 2018
  }'

Check a book out, then return it:

curl -X POST http://localhost:3000/api/books/<id>/checkout
curl -X POST http://localhost:3000/api/books/<id>/return

EXIT STATUS

200OK — request succeeded
201Created — a new book was written
204No Content — deletion succeeded
400Bad Request — validation failed, see error.details
404Not Found — no book, or no route, matched
500Internal Server Error — unexpected failure
